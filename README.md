# Homebrew tap for Pumice

```sh
brew install --cask doeringchristian/pumice/pumice
```

[Pumice](https://github.com/DoeringChristian/pumice) is an extensible, Obsidian-compatible
markdown editor. The app is not signed with an Apple Developer certificate; the cask removes
macOS's quarantine flag after installing so it opens normally.

Upgrade with `brew upgrade --cask pumice`, remove with `brew uninstall --cask pumice`
(`--zap` also removes its settings).
